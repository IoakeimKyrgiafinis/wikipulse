    What is this?

    WikiPulse reads the stream of every edit to English Wikipedia and notices pages that suddenly attract unusual editing, usually because something just happened. This demo replays one recorded day in your browser; nothing runs on a server.

    1. Detect. Per page, edits and distinct editors in sliding 10 and 60 minute windows are compared with the page's normal rate. A burst is a spike.
    2. Group. Spikes about the same story become one event, by links between the pages, timing and the meaning of their summaries.
    3. Understand. A local LLM (qwen3:4b) reads what was added to the pages and extracts a headline, entities and relations; names are linked to Wikidata and every fact keeps the revision it came from.
    4. Answer. GraphRAG over the knowledge graph, briefings written by an analyst agent, an API, a live page and an MCP server.

    Source code on GitHub · README · the one-command quickstart there runs the real pipeline on this day.

    Times are event times in UTC. Page titles, short descriptions and the text the models read come from Wikipedia and are available under CC BY-SA 4.0; each page and fact links to its article or the exact revision. Entity identifiers come from Wikidata (CC0). Headlines, descriptions, entities, relations, briefings and answers were written by local language models and can be wrong. No editor names, IP addresses or edit summaries are included.
